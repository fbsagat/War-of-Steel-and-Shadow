# ⚔️ War of Steel and Shadow

A multiplayer strategy/action game being developed with the Godot Engine, focused on authoritative server architecture, scalable match systems, and real-time gameplay.

This project represents my evolution from traditional backend/web development into multiplayer game engineering and network architecture.

---

## 🎮 About the Project

War of Steel and Shadow is an experimental multiplayer game where the focus goes beyond gameplay mechanics — the project is also a study of:

- Multiplayer architecture
- Authoritative servers
- Match and room management
- Scalable game systems
- State synchronization
- Real-time networking
- Game-oriented backend engineering

The project is being built using a server-authoritative approach, where the server owns the true game state and clients act mainly as controlled interfaces.

---
